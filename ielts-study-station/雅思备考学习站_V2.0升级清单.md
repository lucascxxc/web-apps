## 一、V1 审计结论（升级前）

对既有全部 2491 行代码做了逐行审计 + 58 项 DOM 桩冒烟测试，**结论：V1 并非"空架子"**。测验、听写、审题、批改、T/F/NG、同义替换、精听五步、录音回放等主链路全部真实可运行。

**真实缺口只有 4 块**（用户点名的四块，也是本次升级的核心）：

| 缺口 | 说明 |
|---|---|
| 写作·范文 | 只有审题/批改工具，没有高分范文示例 |
| 写作·题目 | 没有题目生成器，练习需自带题目 |
| 阅读·文章 | 只有判定器/策略，没有分级文章与理解题 |
| 听力·句子 | 只有单词级听写，没有句子级填空练习 |
| 口语·测评 | 只有素材/录音，没有跟读打分反馈 |

## 二、V2.0 新增功能（五大模块）

### ✍️ 写作 V2.0
- **范文示例库**：4 篇完整高分范文（Opinion 父母同住 / Discussion 环境问题 / Problem-Solution 青少年犯罪 / Two-Part 在家时间减少），每篇含：题目、正文、**结构拆解**、**亮点词汇**、**论证技巧 tip**；支持 🔊 朗读、复制、一键「带入审题页」
- **题目生成器**：6 大话题（教育/环境/科技/社会/健康/全球化）× 24 个子题 × 5 种题型模板（Opinion / 利弊 / Discussion / Problem-Solution / Two-Part），一键随机出题、换题、复制、带入审题页

### 📖 阅读 V2.0
- **分级精读**：3 篇分级文章（易 Why We Sleep 298 词 / 中 Urban Green Spaces 356 词 / 难 The Future of Work 415 词）
- 每篇 5 道理解题（单选 + TRUE/FALSE/NOT GIVEN 混合），**逐题作答、即时判分、答案解析**，全部答完显示本篇正确率，支持重做、🔊 朗读全文

### 🎧 听力 V2.0
- **真题句子填空**：10 句真题例句（覆盖 S1 表格/交通、S2 通知/校园、S3 学术/数据、S4 讲座/环境考点）
- 听录音 → 听出空格词 → 输入核对；🔊 常速 / 🐢 慢速、首字母提示、看答案；**编辑距离 ≤2 判"接近"**；进度与正误记录持久化

### 🗣️ 口语 V2.0
- **跟读测评**：8 句口语高频示范（取自万能表达 + Part 2/3 常用句），每句附**发音要点**（音标/重音/连读/易错音）
- **两种跟读模式**：🎤 语音识别（Chrome/Edge 直接开口，自动转写）；✍️ 输入跟读（其他浏览器把句子打出来）→ **词级比对打分**（0-100，多词/少词扣分，完全匹配或编辑距离 ≤1 算命中），逐词绿/红高亮，历史最高分徽章

### 🔧 功能修复（V1 遗留缺陷）
- **修复 `switchSub` 崩溃**：原代码 `('#'+navId).parentNode.id` 对字符串取属性，**任何子导航切换都会抛异常**（按钮高亮正常但面板不切换）。已改为取真实 DOM 元素，V1 的子页切换与 V2.0 的"带入审题"流程均恢复正常
