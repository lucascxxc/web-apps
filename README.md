## 为什么坚持单文件

这些是给自己和别人直接用的，不是给团队维护的工程。

单文件带来的好处很实在：
- 丢进微信就能发，对方点开就能看
- 不会有「环境不对跑不起来」的问题
- 数据不出本地

代价是代码组织上要妥协，以及文件体积偏大（图片内联成了 base64）。
对这个场景，划算。
